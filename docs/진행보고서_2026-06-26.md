## 2. 완료 — 운영 중

배포·DB적용·검증까지 끝난 기능 (2026-06-16~17 검증).

- **모바일 출역** — 전화+PIN4, 1탭 출역. 현장·협력사는 팀장 추종값을 스냅샷 저장
- **노임대장 엑셀** — 표준 + 매사(매사내역서) 서식. 급여형태별(일급/월급/월급·일급) 수식 분기, 일자 2줄 표시
- **매사 2단계 결재** — 작업자→팀장(검토·수정)→관리자, 5단계 상태머신
- **팀장앱 미러링** — 관리자가 팀장 화면을 실데이터로 미러(보기 전용), service_role 가드
- **앱 급여 상세** — 진행 중인 달 숨김, 출역+공제내역+실수령액. 공제는 다운로드 시 서버 자동계산·저장
- **추종/정합화** — 작업자 팀장 추종, 현장↔전문건설사 1:1 규칙, worker resolve 통일
- **출역 GPS 현황** + 현장별 관리자 배정

## 3. 진행 중 — 코드 완성, 배포 전

### 근로계약서 전자서명 (최신 작업, 커밋 `c65e943`)
가장 최근 집중 작업. **코드 완성·로컬 빌드 통과. DB 마이그레이션 적용·배포만 남음(승인 대기).**

- **양식 시스템** — 관리자가 양식 여러 개 등록, 급여형태별(일급/월급/공통) 자동 매칭. 현장↔양식 다대다
- **배포 흐름** — 관리자가 현장+작업자 선택해 배포(issue)해야 앱에 표시. 배포 시 FCM 푸시. 작업자는 앱에서 확인→서명(signature_pad)
- **2가지 배포 방식** — ①현장별 작업자 체크 ②전화번호 붙여넣기(엑셀 복사→조회→배포)
- **불변성** — 서명 시 본문·근무정보·회사정보 동결(snapshot). 계약일만 관리자 수정 가능. 계약기간 시작~종료일 지원
- **PDF** — html2canvas + jsPDF (한글 폰트 임베드 불필요)
- **본문** — 엑셀 '근로계약서(일당직/월급제)' 전체 조항 verbatim 반영 완료

**대기 항목:**
1. DB 마이그레이션 적용 — `20260623130000`, `20260623140000` (적용 대기)
2. **예성건설 회사정보**(`lib/contract/company.ts` 현재 placeholder) — 사용자 입력 필요
3. **계약조건 본문** — 양식에 입력 (코드 변경 불필요)
4. 배포 승인 (`vercel --prod` / push — 별도 승인 필요)

### 출역 파견 (임시 타현장)
앱에서 그날 현장 직접 선택→해당 현장 노임대장 반영. 하루 한 현장 강제. **코드 완성, DB적용·배포 전.**
