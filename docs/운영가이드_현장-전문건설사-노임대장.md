# 운영 가이드 — 현장 · 전문건설사 · 출역 · 성과 · 노임대장

예성건축 시스템에서 **현장 → 전문건설사 → 팀장 → 팀원 → 급여형태 → 노임대장**이 어떻게 연결되는지,
역할별(관리자 / 팀장 / 작업자)로 무엇을 하면 되는지 정리한 문서입니다.

---

## 0. 한눈에 보는 핵심 규칙

| 규칙 | 내용 |
|---|---|
| **현장 ↔ 전문건설사 = 1:1** | 한 현장은 전문건설사 **하나**에만 속합니다. 전문건설사는 **현장 마스터에서만** 지정합니다. |
| **팀장 = 현장 1개** | 팀장은 한 시점에 현장 **하나**를 담당합니다. |
| **전문건설사 자동** | 팀장에게 현장을 배정하면, 그 현장의 전문건설사가 **자동으로** 따라옵니다. (따로 입력하지 않습니다) |
| **팀원은 팀장을 따름** | 작업자는 현장·전문건설사를 **선택하지 않습니다.** 배정된 팀장의 현장·전문건설사를 자동으로 따라갑니다. |
| **원청사는 참조용** | 원청사는 현장 마스터의 **참조 정보**일 뿐, 노임대장·정산에는 관여하지 않습니다. |

> 즉, 전문건설사의 "정답"은 **현장**에 있습니다. 현장만 제대로 지정하면 팀장·팀원·노임대장이 전부 따라옵니다.

---

## 1. 데이터 흐름

```
[현장] ──(1:1)──▶ [전문건설사]          ← 관리자가 현장 마스터에서 지정
   │
   ├─ 팀장 배정 ──▶ 팀장은 그 현장의 전문건설사를 자동 사용
   │                  └─ 팀원(팀장 소속)은 팀장의 현장·전문건설사를 자동으로 따름
   │
   └─ 월별 노임대장(period) = 현장 × 월
         ├─ 출역(공수): 팀장/팀원이 앱에서 입력
         ├─ 성과(매사 물량): 팀장/팀원이 앱에서 월말 입력 (월급/일급 작업자)
         └─ 노임대장 엑셀 = 그 현장·그 달의 출역 + 성과 + (현장의)전문건설사
```

---

## 2. 역할별 안내

### 2-1. 관리자 (웹)

**현장 마스터** (`/worksites`)
- 현장을 등록하고, 각 현장에 **전문건설사(1개)** 를 지정합니다. (목록의 드롭다운에서 바로 선택 → 즉시 저장)
- 원청사도 지정할 수 있으나 **참조용**입니다(정산 무관).
- 현장의 전문건설사를 바꾸면, 그 현장 소속 인원의 전문건설사도 함께 갱신됩니다.

**팀장 배정** (`/managers`)
- 팀장에게 **담당 현장 1개**를 지정합니다.
- 전문건설사는 **자동**으로 표시됩니다(현장에서 파생, 수정 불가). 따로 고르지 않습니다.

**팀원 배정** (`/workers`)
- 작업자에게 **팀장**을 지정합니다. → 작업자는 그 팀장의 현장·전문건설사를 자동으로 따릅니다.

**급여형태** (`/workers`)
- 작업자별 급여형태: **일급 / 월급 / 월급=일급(매사)**.
- **월급/일급(매사)** 작업자만 성과(물량) 입력 대상입니다.

**노임대장** (`/payroll`)
- 현장·월별로 **일반 노임대장**과 **매사 노임대장**을 다운로드합니다.
- 엑셀의 "상호(전문건설사)"는 그 현장의 전문건설사로 자동 채워집니다.

**팀장이 다른 현장으로 이동할 때**
1. `/managers`에서 그 팀장의 **현장만 새 현장으로 변경** → 전문건설사는 자동 변경.
2. 팀장과 같이 이동하는 팀원은 **그대로 두면** 자동으로 새 현장을 따릅니다.
3. 남거나 빠지는 팀원은 `/workers`에서 **팀장만 바꿔** 줍니다.
4. 과거 현장에서 한 작업(출역·성과)은 **그 현장의 노임대장에 그대로 보존**됩니다.

### 2-2. 팀장 (앱)

- **출역**: 매일 1탭으로 출역을 제출합니다. 현장은 **관리자가 배정한 현재 현장**이 자동 적용됩니다.
- **성과(매사)**: 월말 입력 기간(매월 말일~다음달 10일)에 조적·미장 등 물량을 입력합니다. 단가는 **현장 단가표**가 자동 적용됩니다.
- 본인도 작업자이므로 출역·성과가 본인 노임대장에 함께 반영됩니다.

### 2-3. 작업자 (앱)

- **출역**: 매일 1탭 제출. **현장은 고르지 않습니다** — 소속 팀장의 현장이 자동 적용됩니다.
- **성과(매사)**: 월급/일급(매사) 작업자만, 월말 입력 기간에 물량을 입력합니다.
- 현장·전문건설사·단가는 모두 자동입니다. 신경 쓸 필요 없습니다.

---

## 3. 급여형태별 노임대장 처리

| 급여형태 | 정산 기준 | 노임대장 |
|---|---|---|
| **일급** | 출역 공수 × 일당 | 일반 노임대장 |
| **월급** | 고정 월급액 | 일반 노임대장 (총액 고정) |
| **월급/일급(매사)** | 성과(물량 × 단가) 합계 | 매사 노임대장 (출역 공수는 4대보험 신고용으로 표시) |

---

## 4. 월중 현장 이동 — 출역/성과는 어떻게 분리되나

노임대장은 **(현장 × 월)** 단위로 분리 저장되므로, 한 달에 두 현장에서 일해도 각 현장 노임대장에 나뉘어 들어갑니다.

- **출역**: 그날그날 현재 현장 기준으로 제출되므로, A에서 한 날은 A 노임대장, B에서 한 날은 B 노임대장으로 **자동 분리**됩니다.
- **성과**: 앱 성과 화면이 **그 달 일한 현장을 자동으로 나눠** 보여줍니다(현장이 1개면 평소처럼 한 화면). 현장별로 단가표·전문건설사가 자동 적용됩니다.

**입력 가능 시점 (현장별로 다름)**
| 현장 | 입력 시점 |
|---|---|
| **현재 현장(B)** | 평소대로 **월말~다음달 10일** |
| **이전 현장(A, 이동 후)** | **월중에도 즉시 입력 가능** — 그 작업자에겐 이미 끝난 현장이므로 |

> 즉, 관리자가 팀장을 A→B로 옮기면, A는 앱에서 "이전 현장"으로 표시되고 **월중에 바로 A 성과를 입력**할 수 있습니다(기억이 생생할 때). B는 월말에 입력합니다.

---

## 5. 자주 하는 질문

**Q. 작업자가 현장을 잘못 따라가요.**
→ `/workers`에서 그 작업자의 **팀장**이 올바른지 확인하세요. 작업자는 팀장의 현장을 따릅니다.

**Q. 노임대장 상호(전문건설사)가 비어 있어요.**
→ `/worksites`에서 그 **현장의 전문건설사**가 지정돼 있는지 확인하세요. 현장이 단일 진실입니다.

**Q. 팀장 전문건설사를 따로 바꾸고 싶어요.**
→ 따로 못 바꿉니다(의도된 동작). **현장의 전문건설사**를 바꾸면 팀장·팀원이 함께 바뀝니다.

**Q. 원청사를 바꾸면 정산이 바뀌나요?**
→ 아니요. 원청사는 참조용이라 노임대장·정산에 영향이 없습니다.
